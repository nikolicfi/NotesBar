# NotesBar

A tiny macOS menu bar notes app. Click the note icon in the menu bar, type, and your text is saved automatically.

Built with SwiftUI (`MenuBarExtra`).

## Build
1. Open `NotesBar.xcodeproj` in Xcode.
2. Press ⌘R to run, or Product → Archive to build a copy for Applications.

## Download
Grab `NotesBar.zip` from the Releases page, unzip it and drag the app into Applications.
The app isn't notarized, so the first time right-click it and choose **Open**.
If macOS says it's "damaged", run `xattr -cr /Applications/NotesBar.app` in Terminal.
